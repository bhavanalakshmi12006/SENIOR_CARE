========================================================================
  SENIORCARE (SCS) — HOW TO RUN THE PROJECT (MONGODB COMPASS)
========================================================================

1. PREREQUISITES
------------------------------------------------------------------------
* Node.js v18 or higher (Recommended: Node 20+)
* MongoDB installed and running locally on port 27017
  (MongoDB Community Server or MongoDB Atlas)
* MongoDB Compass (GUI to view database and collections)

------------------------------------------------------------------------
2. MONGODB COMPASS CONNECTION
------------------------------------------------------------------------
Open MongoDB Compass:
1. Under "New Connection", enter connection URI:
   mongodb://127.0.0.1:27017
2. Click "Connect".
3. Database Name: senior_care
4. You will see all 14 collections:
   - users
   - seniors
   - caregivers
   - familymembers
   - volunteers
   - checkins
   - emergencies
   - appointments
   - assistancerequests
   - fees
   - payments
   - notifications
   - notificationpreferences
   - recentlyaccesseds
   - auditlogs

------------------------------------------------------------------------
3. SETUP AND SEED DATABASE
------------------------------------------------------------------------
Open a terminal in the project root:

cd backend
npm install
npm run seed

This command will:
* Connect to MongoDB Compass at mongodb://127.0.0.1:27017
* Seed all 6 role accounts, 5 senior profiles, check-ins, active emergencies,
  appointments, assistance requests, fees, and payments.
* Automatically generate sample_data.xlsx in the root directory!

------------------------------------------------------------------------
4. START THE BACKEND SERVER
------------------------------------------------------------------------
In the backend folder:

npm start

* Backend URL: http://localhost:5000
* Realtime: Socket.IO enabled on port 5000

------------------------------------------------------------------------
5. START THE FRONTEND (REACT + VITE)
------------------------------------------------------------------------
Open a second terminal window in the frontend folder:

cd frontend
npm install
npm run dev

* Frontend URL: http://localhost:5174
